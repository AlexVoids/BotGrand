# Фон без ограничений — Android 16

Исходный проект Android Studio на Java (без сторонних библиотек). Поддерживается Android 8–16; `compileSdk/targetSdk = 36`.

## Что делает

- Показывает установленные приложения и поиск по названию / имени пакета.
- Открывает **общий системный список исключений оптимизации батареи** — `Settings.ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS`.
- Открывает **карточку выбранного приложения** — `Settings.ACTION_APPLICATION_DETAILS_SETTINGS`, откуда на большинстве прошивок можно перейти в «Батарея → Без ограничений».
- Открывает **фоновые данные/безлимитный трафик для приложения** — `Settings.ACTION_IGNORE_BACKGROUND_DATA_RESTRICTIONS_SETTINGS` с `package:`.
- Открывает **уведомления приложения** — `Settings.ACTION_APP_NOTIFICATION_SETTINGS` с `EXTRA_APP_PACKAGE`.
- Открывает общие настройки энергосбережения, использования трафика, использования приложений, наложения, специальных точных будильников и полноэкранных уведомлений (если доступны).
- Пытается открыть автозапуск на некоторых версиях оболочек Xiaomi/Huawei/OPPO/vivo. **Это неофициальные панели:** при ошибке открывается обычная карточка приложения.
- Показывает, находится ли приложение в списке исключений Doze. Эта отметка **не равнозначна** режиму «Без ограничений» в фирменных настройках батареи.

Все изменения подтверждает пользователь в системном UI Android. Никаких root, ADB, Accessibility и автоматической выдачи разрешений нет.

## Сборка

1. Откройте папку `BackgroundSettingsAndroid16` в актуальной **Android Studio**.
2. Установите **Android SDK Platform 36** (Android 16) через SDK Manager и JDK 17+.
3. Проект использует **Android Gradle Plugin 8.13.2** (Gradle 8.13). В этой копии нет стандартного бинарного `gradle-wrapper.jar`: используйте локально установленный Gradle 8.13 или создайте стандартный wrapper командой `gradle wrapper --gradle-version 8.13` перед синхронизацией (после этого собирайте `./gradlew assembleDebug`).
4. В Android Studio: **Build → Build APK(s)**. Получится `app/build/outputs/apk/debug/app-debug.apk`.
5. Установите полученный APK на телефон.

**Замечание о публикации в Google Play.** `QUERY_ALL_PACKAGES` нужен утилите, чтобы показать вообще все приложения, в том числе без значка. Google Play ограничивает использование этого доступа. Для публикации потребуется обоснование либо отказ от полного списка и переход на выбор только видимых приложений.

## Что Android НЕ разрешает

Обычное стороннее приложение не может программно ставить другим приложениям «Без ограничений», выдавать чужие разрешения или гарантировать их работу в фоне. На разных прошивках названия и доступность экранов различаются. Некоторые настройки (будильники, полноэкранные уведомления) видны только приложениям, действительно использующим соответствующие функции.
